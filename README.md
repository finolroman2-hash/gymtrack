# gymtrack

Native Android app for logging strength and hypertrophy workouts and tracking training progress.

## Features
- Workout and routine logging
- Training load calculations
- Progress visualization
- Built-in database of 400+ fitness educational and conceptual entries (JSON)

## Tech stack
- Kotlin
- Android (Gradle)
- JSON data model

## Run locally
1. Install Android Studio.
2. Clone this repository.
3. Copy `local.properties.example` to `local.properties` and adjust it for your machine.
4. Open the project in Android Studio and run the `app` module.
